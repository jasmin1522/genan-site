画像差し替え手順
================

1. `hero.jpg` をこの `images/` フォルダに配置し、`css/style.css` 内の Hero セクションコメントを解除してください。
2. `recommend-1.jpg` `recommend-2.jpg` `recommend-3.jpg` を配置し、`css/style.css` 内のおすすめメニュー画像コメントを解除してください。
3. `exterior.jpg` を配置し、`css/style.css` 内の外観写真エリアコメントを解除してください。
4. OGP画像を用意する場合は `ogp.jpg` を任意の公開ディレクトリへ配置し、各HTMLの `og:image` を更新してください。
5. Googleマップ埋め込みを行う場合は `access.html` の TODO コメントに沿って iframe を差し込んでください。
